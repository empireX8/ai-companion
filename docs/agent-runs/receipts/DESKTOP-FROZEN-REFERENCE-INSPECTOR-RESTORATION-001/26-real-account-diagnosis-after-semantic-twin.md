## Separation rule

With the semantic twin proving the live provider can supply reference-contract
composition when equivalent data exists in production storage, absences on a
real populated account are **not** treated as presentation/provider defects by
default.

| Absence on real account | Classification |
|-------------------------|----------------|
| Object/title never captured | genuinely not yet observed |
| Pattern/claim/MU not produced by pipeline | not generated by the intelligence pipeline |
| Generated but not written to DB | not persisted |
| Persisted but no UEL / pointer / affected-object link | not linked |
| Linked but thin evidence packet | insufficient evidence |
| Honest empty / gated by readiness | deliberately unavailable |
