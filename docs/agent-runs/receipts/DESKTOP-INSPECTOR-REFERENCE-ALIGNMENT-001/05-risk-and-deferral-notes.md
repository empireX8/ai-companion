# Risk And Deferral Notes

Risks:
- Live visual validation is partial because the local browser session reached Clerk sign-in instead of an authenticated selected-object Inspector.
- Source-level tests guard class drift, but they do not replace product-owner visual acceptance.
- Real production data may expose longer labels, missing receipt titles, or selected-object states that still need visual tuning.

Deferrals:
- Today action routing.
- Decisions flow.
- Capture Life Data UX.
- Watch For / Fieldwork routing.
- Map center-panel object presentation.
- Explore grounding.
- Timeline continuity.
- Voice input.
- Import.
- Branding polish.
- Profile/settings.
- Mobile Inspector.
- Auth/middleware route access for dev visual harnesses.

What must remain true:
- Inspector claims remain evidence-backed.
- Weak or missing evidence remains visible.
- Raw linked paths and opaque IDs remain hidden from user-facing Inspector states.
- Correction actions remain correctable, not certainty-implying.
- Movement receipt counts do not imply certainty.
