# Blocker Gap Map

## Blockers

1. Inspector UX completion
- Evidence/context is rendered as dense paragraph dumps instead of readable intelligence panels.
- Pattern labels, conflicts, goals, movement, and receipts are mixed together.
- The trust mechanic is weakened because the user cannot read or traverse evidence cleanly.

2. Map object presentation cleanup
- Model Goals appear empty.
- Mind Context is shallow or incomplete.
- Supporting and conflicting evidence states are often generic, empty, or unavailable.
- Map still feels conclusion-heavy instead of durable model-led understanding.

3. Today action routing repair
- Today is visually closest to acceptable, but its action buttons expose broken downstream flows.
- Re-entry actions do not preserve semantic differences between capture types.

4. Capture Life Data UX contract
- Capture exists, but presents as a generic chat/journal surface.
- The current shape does not distinguish evidence, decision, conflict, outcome, correction, and context capture.

5. Decisions flow repair
- Decision actions are dead or incomplete.
- Outcome recording is not operationally honest because it can record without collecting an outcome.

6. Watch For / Fieldwork architecture decision
- Watch For and Fieldwork are mixed in naming, routing, and back behavior.
- The current page feels unfinished and does not explain its observation/test contract clearly.

## Partial but not primary blockers

7. Explore grounding repair
- Explore loads and fits the shell better than some other pages, but model grounding and review/update flows are incomplete.

8. Timeline connection repair
- Timeline does not read like a calendar, but continuity back into evidence/model surfaces is weak.

## Cross-cutting product requirements

9. Voice input coverage pass
- Every text input should support voice capture before launch readiness is claimed.

10. Import defer / MVP decision
- Import is currently dead and should remain logged until MVP scope decides whether it is required.
