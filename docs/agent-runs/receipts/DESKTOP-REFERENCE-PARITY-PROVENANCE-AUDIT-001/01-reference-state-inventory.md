## Cross-recording reference contracts

The recordings repeatedly require:

1. One selected object to remain coherent across page, Inspector title and tab.
2. Evidence/Context to include source/provenance, rationale, context, related objects and corrections where appropriate.
3. Model Movement to separate selected-object movement from global recent movement.
4. Related/context rows to be navigable.
5. “Ask in Explore” to carry meaningful object context, not merely switch pages.
6. Visible write-like actions to persist or be explicitly labelled as non-persistent.
7. Reports to be real objects with cited evidence, not an overlay populated from fixtures.

## Reference omissions

The recordings do not fully specify:

- durable correction lifecycle and reversal;
- decision option editing and outcome schema/UX;
- how an end user authors depth-safe rationale and graph-slot links;
- how fieldwork results become evidence/model movement;
- report generation/versioning;
- error, offline, conflict and permission states;
- sparse production states for each surface;
- exact AI contracts for hypotheses, grounding, movement and review.

Those are marked `G_MISSING_UX_CAPABILITY` or `H_REFERENCE_AMBIGUITY` in the production matrix; they must not be filled with fabricated output.
